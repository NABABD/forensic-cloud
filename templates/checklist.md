# Checklist d’acquisition

## Autorisation

- [ ] Case ID créé
- [ ] Incident Commander identifié
- [ ] Juridique/DPO consulté
- [ ] RH consulté si nécessaire
- [ ] Client consulté si nécessaire
- [ ] Périmètre exact validé
- [ ] Transfert inter-région/pays validé

## Volatile

- [ ] Heure UTC
- [ ] RAM
- [ ] Processus
- [ ] Services
- [ ] Sessions
- [ ] Connexions
- [ ] Routes
- [ ] Cache ARP/neighbor/DNS
- [ ] Modules/pilotes
- [ ] Conteneurs
- [ ] Journaux locaux
- [ ] Stockage éphémère

## Persistant

- [ ] Tous les disques identifiés
- [ ] Snapshots créés
- [ ] Identifiants enregistrés
- [ ] Copie forensic réalisée
- [ ] Clé de chiffrement vérifiée
- [ ] Copie d’analyse distincte

## Plan de contrôle

- [ ] Métadonnées VM
- [ ] IAM
- [ ] Réseau
- [ ] Audit logs
- [ ] Alertes sécurité
- [ ] Journaux réseau
- [ ] Configuration de rétention

## Scellement

- [ ] SHA-256
- [ ] SHA-512
- [ ] Vérification après transfert
- [ ] Stockage immuable
- [ ] Chaîne de custody
- [ ] Accès temporaires révoqués
- [ ] Rapport final
